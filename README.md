## 把分散的跟进，放回一条清晰的行动线

客户多了以后，难记住的往往不只是名字：**今天该联系谁、上次聊到哪里、下一次准备做什么**，都需要随时找得到。

跟进宝围绕这三个问题，把客户信息、沟通记录和提醒连接起来。

## 从一次沟通，到下一次行动

| ① 建立客户 | ② 记录沟通 | ③ 确认下一步 | ④ 回看与复盘 |
| :--- | :--- | :--- | :--- |
| 填写客户摘要、阶段和优先级 | 留下沟通方式、结果与关键内容 | 确认动作和时间，形成下一次提醒 | 从今日行动进入任务，回看时间轴与跟进趋势 |

**建议体验路径：** 打开示例客户 → 查看画像和沟通记录 → 下滑到「AI军师」 → 按需填写客户异议 → 点击「生成 AI 跟进建议」 → 核对并修改草稿 → 选择联系时间、确认采用 → 返回首页查看下一步安排。

首次访问可体验 **20 位虚拟寿险／健康险客户、80 条连续沟通记录、7 个跟进阶段**。也可以记录一次新的沟通，更新客户阶段，再生成建议。

以下命令仅适用于本仓库已有的静态原型，不会启动最新在线版的 AI 服务。

### 启动静态预览

```sh
git clone https://github.com/yilin6868/followup.git
cd followup
python3 -m http.server 8000
```

浏览器打开 [http://localhost:8000](http://localhost:8000)。

### 修改与构建

```sh
python3 tools/genjin/build.py
cp tools/genjin-mvp.html index.html
```

构建器把脚本、样式与运行时内联为单个 HTML。橙色主题、状态栏及手机全屏入口在 `tools/genjin/build.py` 中调整。

```text
followup/
├── index.html                  # 可直接打开、可部署的单文件页面
├── README.md                   # 产品介绍与使用说明
└── tools/genjin/
    ├── build.py                # 主题、适配与打包逻辑
    ├── dashboard.js            # 交互脚本
    ├── styles.css              # 基础样式
    ├── *runtime.js             # 浏览器运行时
    └── THIRD_PARTY_NOTICES.md   # 来源与第三方声明
```

上述构建产物可用于静态预览。最新在线演示已部署在火山引擎，由页面与服务端 AI 接口共同提供功能；仅使用静态托管或 `python3 -m http.server` 无法提供真实 AI。最新 AI 后端尚未同步到本仓库。

## 关于当前版本

- **在线 AI 原型：** 已接入真实模型，可在「AI军师」生成跟进草稿；目前为网页交互演示，尚未生成微信小程序。
- **浏览器本地存储：** 记录保存在当前浏览器的 `localStorage`，不同浏览器或域名之间不自动同步，没有云端客户账户或 CRM 同步。
- **顾问确认行动：** AI 结果是待核对的草稿，不会自动联系客户或修改客户阶段。选择时间并确认采用后才保存计划；当前不学习或长期记忆个人语言偏好。
- **数据与模型调用：** 点击生成时，当前客户的画像、最近沟通和所填异议会经服务端发送给模型服务。姓名、联系人字段不主动传入，但自由文本仍可能包含个人信息，请使用虚拟或去除敏感信息的资料。密钥仅由服务端读取。
- **示例数据：** 画像、金额和沟通记录均为虚构案例，不代表实际产品报价、投保、核保或理赔结论；AI 内容仍需对照真实情况和正式条款核对。
- **提醒方式：** 当前通过页面内待办和日历展示安排，没有微信自动发送消息或后台推送功能。
- **体验限制：** 公开演示设有调用频率、并发和用量限制。出现繁忙或额度提示时，可稍后重试；不保证任何时候都能即时返回。
- **语音按需使用：** 语音输入依赖浏览器支持与用户授权，不支持时可直接输入文字。
